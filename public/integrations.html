Send traces from your application

Use the returned token in an Authorization header. The receiver accepts spans[] JSON or OTLP JSON resourceSpans. Do not send passwords, API keys, raw prompts or customer PII in span attributes.

curl -X POST https://taskops-ai-data.hatchable.site/api/ingest/traces \ -H "Authorization: Bearer YOUR_TASKOPS_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "source": "my-agent-service", "spans": [{ "trace_id": "trace-001", "span_id": "span-001", "name": "agent.run", "kind": "internal", "status": "ok", "start_time": "2026-11-11T08:00:00Z", "end_time": "2026-11-11T08:00:01Z", "attributes": { "gen_ai.system": "openai", "gen_ai.operation.name": "chat" } }] }'
